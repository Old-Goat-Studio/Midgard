# Midgard's built-in UI fonts

Built into every game (milestone 6.0) for its menus, screens and HUD. They are the one exception to
"bundled assets are CC0 only" (Phase6_Roadmap.md, decided 4 November 2026): fonts under the SIL Open
Font License 1.1, which allows them to be bundled and embedded in any software as long as the
licence goes with them. Exported games list both, with the licence text, in
THIRD_PARTY_NOTICES.txt (tools/third_party.json).

| File | Font | Licence | From |
|---|---|---|---|
| `Inconsolata.otf` | Inconsolata (Medium), the default | OFL 1.1, `OFL-Inconsolata.txt` | Raph Levien, https://levien.com/type/myfonts/inconsolata.html |
| `OpenDyslexic3-Regular.ttf`, `OpenDyslexic3-Bold.ttf` | OpenDyslexic 3, for players who read more easily with it | OFL 1.1, `OFL-OpenDyslexic.txt` | Abelardo Gonzalez, https://opendyslexic.org |

The files are unmodified (from the Master Asset Library). In RML and RCSS their families are
`Inconsolata` and `OpenDyslexic`.
