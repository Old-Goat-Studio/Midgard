# Themes

Editor colour themes. Every `.qss` file here appears in the editor's **View ▸ Themes** menu,
named after the file (`solarized-light.qss` → *Solarized Light*). Images a theme needs go in a
`<name>-icons/` folder beside it. See the Theme Scheme section of `midgard_roadmap.md`.

The signature **Yggdrasil** theme is added in Phase 1.
